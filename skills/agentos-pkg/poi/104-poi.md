# Skillware POI Catalog

Canonical class suffixes map to the existing selectable producer kinds in order:
`Parse.Error`=`parse-error`, `Unresolvable`=`unresolvable`,
`Never.Built`=`never-built`, `Stale.Build`=`stale-build`,
`Hand.Edited`=`hand-edited`, `Copy.Drift`=`copy-drift`,
`Derived.Stale`=`derived-stale`, `Dependency.Undeclared`=`undeclared-dependency`,
`Dependency.Unhonored`=`unhonored-dependency`,
`Dependency.Dangling`=`dangling-dependency`,
`Dependency.Uncited`=`uncited-dependency`,
`Context.Assembly.Bypass`=`context-assembly-bypass`,
`Note.Malformed`=`malformed-note`, `Address.Mismatch`=`address-mismatch`,
`Callout.Legacy`=`legacy-callout`, `Annotation.NonSkw`=`non-skw-annotation`,
`Attachment.Illegal`=`illegal-attachment`, `Header.Missing`=`missing-header`,
`Edition.History.Missing`=`missing-edition-history`,
`Edition.History.Record.Invalid`=`invalid-edition-history-record`,
`Edition.Session.Duplicate`=`duplicate-edition-session`,
`Edition.Support.Unresolvable`=`unresolvable-edition-support`, and
`Git.Edition.Unsupported`=`unsupported-git-edition`.

****

## Skillware.Linter/Parse.Error

- [DF] the source is below the parse floor because machinery is malformed or a construct is unclosed
- [CT] this compatibility POI is accompanied by a distinct `Closure.Parser` diagnostic
- [PR] fix the source; parse errors gate that file's other checks and are not blessable

****

## Skillware.Linter/Unresolvable

- [DF] a `--from` target does not resolve at its declared address
- [PR] fix the address or restore the target; this class is not blessable

****

## Skillware.Linter/Never.Built

- [DF] a source exists without a corresponding lock entry
- [PR] run `agentos skw build`

****

## Skillware.Linter/Stale.Build

- [DF] the on-disk target matches the lock while a fresh compilation differs
- [PR] run `agentos skw build`

****

## Skillware.Linter/Hand.Edited

- [DF] a compiled target was edited outside its source
- [PR] move the intended content into the source or rebuild over the target

****

## Skillware.Linter/Copy.Drift

- [DF] a copy body no longer equals the expansion of its target
- [PR] run `agentos skw build`

****

## Skillware.Linter/Derived.Stale

- [DF] a dependency changed since the derived body was written
- [PR] re-derive the source body or explicitly bless the current instance

****

## Skillware.Linter/Dependency.Undeclared

- [DF] compiled text mentions a resolving dotted name without declaring its dependency
- [PR] declare the dependency with `--from` or explicitly bless the current instance

****

## Skillware.Linter/Dependency.Unhonored

- [DF] a declared dependency is not mentioned in compiled text
- [PR] mention the dependency, remove the declaration, or explicitly bless the instance

****

## Skillware.Linter/Dependency.Dangling

- [DF] a declared `--from` target no longer resolves in configured depots
- [PR] restore or repoint the target, or explicitly bless the instance

****

## Skillware.Linter/Dependency.Uncited

- [DF] a `--cite` target is not explicit in the compiled surface
- [PR] cite the target visibly, change its role, or explicitly bless the instance

****

## Skillware.Linter/Context.Assembly.Bypass

- [DF] a surface depends on assembly-covered source without loading its context assembly
- [PR] add the required `--dev-from` or explicitly bless the intentional bypass

****

## Skillware.Linter/Note.Malformed

- [DF] a `--note` or `--supp` lacks its act code or trailing anchor
- [PR] add the missing type and support anchor in the source

****

## Skillware.Linter/Address.Mismatch

- [DF] a fenced element name differs from its declared address
- [PR] align the element name and address

****

## Skillware.Linter/Callout.Legacy

- [DF] an inert legacy `[!skw]` callout remains outside a fence
- [PR] rewrite it using current `$kw` grammar

****

## Skillware.Linter/Annotation.NonSkw

- [DF] a comment on a managed code surface is not represented as a `Skw.Annotation`
- [PR] encode it as an annotation, remove it, or explicitly bless the instance

****

## Skillware.Linter/Attachment.Illegal

- [DF] a Skw block attaches outside the surface's sanctioned point set
- [PR] move it to a sanctioned point or change the owning attachment policy

****

## Skillware.Linter/Header.Missing

- [DF] a managed code file lacks the required line-one annotation
- [PR] add the line-one header or change the owning presence policy

****

## Skillware.Linter/Edition.History.Missing

- [DF] a configured file has no valid edition and session association
- [PR] inspect Git and Chatlas, then record a supported association

****

## Skillware.Linter/Edition.History.Record.Invalid

- [DF] an edition-history record violates the existing service schema
- [PR] repair or replace the invalid record

****

## Skillware.Linter/Edition.Session.Duplicate

- [DF] one file edition and session association is recorded more than once
- [PR] remove the duplicate record

****

## Skillware.Linter/Edition.Support.Unresolvable

- [DF] an edition and session support set cannot be resolved through Chatlas
- [PR] repair the exact session and event support members

****

## Skillware.Linter/Git.Edition.Unsupported

- [DF] a Git edition has no resolvable edition and session association
- [PR] recover candidate chats and record supported associations
