# Tara Tape POI Catalog

These classes preserve existing Tara tape conformance messages. Their
evaluation and repair protocols have not yet been reviewed.

****

## Tara.Tape.Linter/Path.NotDirectory

- [DF] placeholder for legacy Tara issue `path is not a directory`
- [RJ] evaluation and resolution guidance is not yet established
