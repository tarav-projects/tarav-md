# Chatlas Commit POI Catalog

****

## Chatlas.Commit.Linter/Session.Mismatch

- [DF] a zip-transcript agent summary names a session different from its source transcript
- [CT] committing the staged artifact is refused

****

## Chatlas.Commit.Linter/Turn.CountMismatch

- [DF] a zip-transcript agent summary does not preserve the source turn count
- [CT] committing the staged artifact is refused

****

## Chatlas.Commit.Linter/Turn.InvalidObject

- [DF] a zip-transcript agent summary contains a turn that is not a JSON object
- [CT] committing the staged artifact is refused

****

## Chatlas.Commit.Linter/Turn.RoleMismatch

- [DF] a summary turn does not preserve the role at the same source position
- [CT] committing the staged artifact is refused

****

## Chatlas.Commit.Linter/Turn.TextNotString

- [DF] a summary turn's text is not a string
- [CT] committing the staged artifact is refused

****

## Chatlas.Commit.Linter/Turn.UserTextNotVerbatim

- [DF] a user turn does not preserve its source text verbatim
- [CT] committing the staged artifact is refused

****

## Chatlas.Commit.Linter/Turn.AssistantTextBlank

- [DF] an assistant turn has been reduced to blank text
- [CT] committing the staged artifact is refused
- [CT] every blank turn index is reported at once, so a partial fill can resume from the refusal

****

## Chatlas.Commit.Linter/Compression.Insufficient

- [DF] a summary retains too much of the source assistant text to be a compression product
- [CT] committing the staged artifact is refused
- [CT] measured over assistant text only, because user turns are verbatim by contract
- [CT] applies only above a source-size floor, since small sessions are often already minimal
- [CT] `--allow-low-compression` commits anyway and records the exemption in the product manifest

****

## Chatlas.Commit.Linter/Compression.RegionUntouched

- [DF] a summary compressed some of the transcript while leaving whole regions essentially untouched
- [CT] committing the staged artifact is refused
- [DF] the transcript is windowed by source assistant bytes; a window retaining almost all of its source is untouched
- [CT] a single dense window is tolerated, since some regions are legitimately incompressible
- [CT] refusal requires the untouched windows to be a material share of the transcript
- [CT] every untouched window is reported at once, with its turn range
- [CT] `--allow-low-compression` waives this the same way it waives the global floor
