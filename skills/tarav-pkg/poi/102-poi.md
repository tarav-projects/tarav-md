# Foundation Validator POI Catalog

These classes preserve the existing validator conditions. Evaluation and repair
guidance remains intentionally incomplete where the owning system has not
reviewed it.

Producer-code mapping:

- Anchory: `Meta.Invalid`=`invalid-meta`, `Shard.Name.Invalid`=`invalid-shard-name`, `Json.Invalid`=`invalid-json`, `Shard.Invalid`=`invalid-shard`, `Record.Invalid`=`invalid-record`, `Anchor.Invalid`=`invalid-anchor`, `Anchor.Misplaced`=`misplaced-anchor`, `Anchor.Duplicate`=`duplicate-anchor`, `Anchor.Tagless`=`tagless-anchor`
- Bloberia: `Json.Invalid`=`invalid-json`
- Markdown blocks: `Headings.None`=`no_headings`, `CodeFence.Unclosed`=`unclosed_code_fence`, `Preamble.BeforeFirstBlock`=`preamble_text_before_first_block`, `Separator.OutsideBlockSemantics`=`separator_outside_block_semantics`, `Heading.Title.Empty`=`empty_heading_title`, `Block.TooLong`=`block_too_long`, `Heading.Title.DuplicateSameLevel`=`duplicate_heading_title_same_level`
