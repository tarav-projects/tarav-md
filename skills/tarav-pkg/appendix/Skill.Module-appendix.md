## Skill.Module/Context.Assembly.Module

- [DF] a `Context.Assembly.Module` is a `Skill.Module` whose product is the curated, complete context universe for one coherent subject ^c20260725-135u
- [DC] using an assembly-covered source requires a companion `--dev-from` edge, so the consumer's `Builder.Agent` loads that whole context before developing the surface ^c20260725-119u
- [CT] assembly coverage does not own or mediate its sources; builders may still depend on, copy, derive, or cite them directly ^c20260725-61u
- [CT] several assemblies may cover the same source, and their applicable builder-context requirements accumulate ^c20260725-84u
- [PR] a shared assembly stabilizes development coherence across builders while each running agent loads only the context selected by its actual workflow ^c20260725-155u
- [RJ] an assembly dependency neither prescribes what a builder materializes nor forces the assembly into runtime context ^c20260725-169u
