# Config.Injected.ENV — Appendix

****

## Config.Injected.ENV/Examples

- profile `env` is config injection
- project provider env is config injection
- config injection may express behavioral preferences
- config injection may express provider policy values
- examples: profile-declared disable flags, custom provider env, user-selected launch env
- non-example: selected home mapped to `CODEX_HOME`
- non-example: managed credential token injected from account state
- tests should show config env only when the test config declares it
- related: `Harness.Injected.ENV`, `Provider.Instance`, `Agentos.Agent.Adapter`
