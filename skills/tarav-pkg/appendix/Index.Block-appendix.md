## Index.Block.Catalog

- `Index.Block.Catalog` is the worked example set for writing `Index.Block`s — concrete blocks paired with the rules
- it indexes the document @tarav-pkg/references/index-block-catalog.md, which holds the examples in full
- positive examples model atomic, orthogonal lines — the granularity to imitate
- negative examples catalog the failure modes — welded lines, headings restated as bullets, implementation/status dumped into a block
- its purpose is calibration: the concrete form bar the compressed `Index.Block` rules can't carry alone
- the document owns the depth; this block is only its index entry, read under `Index.Block`
