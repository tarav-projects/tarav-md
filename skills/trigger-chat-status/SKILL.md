# Trigger: Chat Status

Reconnect the user with the current session state. Produces a todo list and context summary from the chat.

## Activation

Use when the user asks "status", "catch me up", "what are we doing?", "what's next?", "anything left?", "what's missing?", or similar reconnect requests — and no explicit hugentic workflow is active.
