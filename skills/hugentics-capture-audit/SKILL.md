# Hugentics Capture Audit

Scan the chat to check whether significant ideas, decisions, approvals, issues, or implementation state are only present in the chat.

Captured means stored in a more permanent setting than the chat, such as an active artifact, index block, appendix, reference, issue report, or implementation request.

## Activation

Use when the user asks for a capture audit, "did we miss anything?", or similar. Works during any Hugentic workflow: design session, impl-req design, or impl execution.

## What To Load

- Load `agentos-hugentics/references/capture-audit.md` for the full audit protocol.
- Identify which workflow is active and audit against its surfaces.
- Report findings and let the user decide what to capture or update.
