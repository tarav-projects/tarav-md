## Callable Context and Type model nodes

The User approved `obj.context.explore(type=ObjectGroup)` with callable
shorthand and `SomeType.context.model`, preserving namespace inheritance and
explicit composition. A Type's partial model has identified Ships as nodes,
with paths as labels and each node's own Context. Class and external
contributions are both allowed. Built as request 911; see
[Context Graph](../context-graph.md), "Callable namespace and partial Type models".
The initial implementation supplies TypePath nodes, a composed model folder,
provider hooks and default create-only retention. Code correspondence checks
and the separate external-annotation workflow remain future work.
