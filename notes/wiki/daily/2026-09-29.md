## Configured Python process launching implemented

The user invoked Execute for [826](../../../../tarav-py/notes/live/826-tarav-process-launching-impl-req.md).
Tarav now has a typed Python Workflow runner contract, one shared configured
subprocess engine, and `tarav run` with current or Project configuration.
Project launch fields come from `.tarav/project.json`, and the bootstrap path
projects those common fields without loading the product's concrete Project
Type. Existing generated harnesses retain their specialized package bootstrap;
declared product packages can use their own manifest and environment. The full
suite passes 1,386 tests, Ruff passes, and the installed CLI smoke check ran in
Tarav's tool environment. See [Projects](../projects.md#explicit-tarav-process-launching)
for the implemented boundary and source links.
