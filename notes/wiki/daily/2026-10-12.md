## The status command was too slow; suites return as detectors

`tarav project status` ran the whole pytest suite of `tarav-py` on every
call. The User wants it to be the constant mechanical feedback for agents,
so it cannot be slow, and agents should be able to run a subset.
<!-- tarav.breadcrumb 8ab69e79f90adb9df7a0ac777731dd392b134e47c85a3f62d93aec4839dc2fbc -->
<!-- tarav.breadcrumb 88cf5f3360149233034d1e47ce7dcbbccbc601288c13b18373a0dcb4b5c1d11d -->

Running a subset needed a new closing rule, and the discussion brought the
suite back in a different form from the one removed the day before. A suite
is a class with an identity. It does not contain checks: it contains the
code that runs them, because checks depend on situations and cannot be
listed beforehand. It holds the results of its one run, and it can run whole
or filtered. The signal is gone when the detector no longer detects it.
