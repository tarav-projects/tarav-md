## POI tracking records changes, not runs

Reviewing the 883 result, the User rejected rewriting every record on every
check run. Tracking appends an entry only when a POI's status changes; a run
that changes nothing writes nothing.
<!-- tarav.breadcrumb 3f98acba7fda -->

The detection follows the situation pattern: an explicit object holds the
status the tracker assigns, its hash is compared with the last one, and the
object is stored beside the hash. No event system and no smartness in the
code. A revision of 883 has not been requested yet. The
[POI system](../poi-system.md) has the details.
