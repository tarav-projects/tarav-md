## Monitor auto-prime pings work again

The account monitor's pings had failed for every Codex account since 2026-09-09 because OpenAI rejects the `gpt-5.4-mini` ping model for ChatGPT-account Codex logins. The User asked for the ping to work again in a simple form.
<!-- tarav.breadcrumb 71ea54013e08a6db24bfb2121474c7e9b9dfbb390ba1c4d1e5943cfa970ef7cb -->

Instead of a new workflow, the existing `auto-prime-zero-limits` workflow was cut down to one rule: every `interval_sec` (10 minutes by default), ping each configured target whose last burst reading is below 5%. The [Agent accounts monitor](../agent-accounts-monitor.md) note records the rule and [Impl.Req 869](../../../../tarav-py/notes/live/869-auto-prime-burst-threshold-impl-req.md) records the implementation and checks.
