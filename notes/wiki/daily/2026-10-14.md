## A link is declared; its Type checks the prose

The User pasted an open `UnannotatedOutputLink` action of `tarav-hugentics`
and asked for an explanation from first principles. It reported a Markdown
link typed into a block without a declaration.
<!-- tarav.breadcrumb a09a8f93bcf4cad699141ebb5d7df7e1b3ba4550d13dc912e2b6756d63c67e9f -->

The User did not like the model of declared and authored links and asked for
its grounding. No User turn grounded the prose parsing or the link slot.
<!-- tarav.breadcrumb 7fb295a5ccb08bedc511d4fc10959d9c86f8457766f2758c5b23b868be4b543d -->

The User redesigned it: a link is declared only, and a link Type may carry
checks on the prose. The rule is general for SKW: blocks declare, the system
checks that declarations fit together, later mechanisms check or score them.
Built as request 904. See [Skillware](../skillware.md), section "Links are
declared; a prose part checks the text (904)".
