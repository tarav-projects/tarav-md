places of work and Projects relate. Tarav does not model the Python library; a
Project is an object inside one, a library can hold several, and where their
code sits is a packaging choice. A development folder can be a root Project
over child Projects, which the User wants for `taravangian-project` too. See
[projects](../projects.md#places-libraries-and-project-classes).
