## ChatSession navigation design

The user selected ChatSession as the session object distinct from retained
representations, and approved designing the first Session → Model navigation
slice. The accepted API starts with `sessions.get(session_id).open()` and
`session.model()`; deeper Turn/Message navigation remains progressive work.
Existing retained formats should stay unchanged. See
[Chatlas Normal Model](../chatlas-normal-model.md#session-and-representation-navigation)
and [823](../../../../tarav-py/notes/live/823-chat-session-model-navigation-impl-req.md).
No product implementation was performed in this Design pass.

## Project-local Python harness design

The user proposed a default `.tarav/env` environment managed with uv, containing
Tarav and a project-specific package with a concrete `TaravProject` subtype.
The follow-up selected implementation Design. The resulting
[824](../../../../tarav-py/notes/live/824-project-local-python-harness-impl-req.md)
coordinates the proposed bootstrap; no product code or environments were
changed in this pass. See [Projects](../projects.md#project-local-python-harness).
