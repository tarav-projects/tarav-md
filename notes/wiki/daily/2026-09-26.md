## Explicit Type Workflow

The User accepted an explicit `TypeWorkflow`, specifically the ownership
relationship `entity(TaravClass).workflow` pointing to that workflow. The
decision is captured in [the record framework](../record-framework.md#explicit-type-workflow);
this capture does not implement the ownership change.
<!-- tarav.breadcrumb 93e0b6e337c17f73a10fe77eef632f6e70b642bf322703c367cfa7d2ac6135b9 -->

The discussion separated foundational code location from semantic ownership:
code can remain in `tarav.kernel` while types belong to specialized workflows.
The User also affirmed that the Type Graph expresses explicit type semantics,
not necessarily all of the system's meaning.
