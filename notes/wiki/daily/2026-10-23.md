## Programs defined by Project classes

The User settled on Programs as ordinary Tarav classes defined in Projects,
using their existing trusted Python environment. The shared base provides
execution and persistence; concrete definitions supply States, Actions and
allowed connections. The User then requested an implementation request and
execution, with Project Monitor changes left for another discussion.
<!-- tarav.breadcrumb 581463e78683 -->
<!-- tarav.breadcrumb b1bcd94577e3 -->
<!-- tarav.breadcrumb 48f3d8a578d1 -->

A State produces checks reused by the StateAction that reaches it and by later
status under its token. This aligns arrival with the promise of maintaining
that State. A token selects which conditions to check; product drift can still
occur and must be reported. The refined design lives in
[Programs](../programs.md#project-defined-checked-programs--2026-10-23).
